## 🚀 What's New in v3.5

- **True YouTube Bottom Navigation**: Pinned 3 primary bottom tabs (**Home**, **Save**, **History**) with clean icons and labels.
- **Header Settings & Brand Icon**: Quick-access settings cog placed right before the app logo in the top bar.
- **Smooth Auto-Hide Animations**: Both top and bottom bars smoothly slide away on scroll-down and slide back on scroll-up with zero empty black space.
- **Edge-to-Edge Feed Layout**: Video cards seamlessly fill the entire display height.
- **Live Stream Filter**: Homepage clean from live-stream clutter with random discovery injection.

## 📥 Installation Guide

### Option 1: Direct Download (Standard Android)

1. Tap the [**Big Download Button**](https://github.com/Bit-manipulators/youtube-without-ads/releases/latest/download/AdFreeYT_v4.4.apk) above or visit [Releases](https://github.com/Bit-manipulators/youtube-without-ads/releases/latest).
2. Download `AdFreeYT_v4.4.apk`.
3. Open the downloaded file and select **Install** (allow "Install from Unknown Sources" if prompted).

### Option 2: Termux

If you are running Termux with storage permission:

```bash
# Download latest release directly
curl -L -o AdFreeYT_v4.4.apk https://github.com/Bit-manipulators/youtube-without-ads/releases/latest/download/AdFreeYT_v4.4.apk

# Install via Android Package Installer
termux-open AdFreeYT_v4.4.apk
```

## 🛠️ Building from Source

```bash
git clone -b newpipe https://github.com/Bit-manipulators/youtube-without-ads.git
cd youtube-without-ads
./gradlew assembleContinuous
```

The output APK will be generated at `app/build/outputs/apk/continuous/app-continuous.apk`.
